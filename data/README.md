# 데이터

## 원본
- 서울 열린데이터광장 「서울시 부동산 전월세가 정보」(OA-21276)
- 파일 : `서울특별시_전월세가_2025.zip` (2025년 계약 1,084,942건)
- 원본은 용량 때문에 레포에 포함하지 않음

## 가공 노트북
- `neighborhood_data.ipynb` (Google Colab)

## 정제 기준
| 기준 | 처리 |
| --- | --- |
| 전월세구분 | 월세만 |
| 건물용도 | 아파트 제외 |
| 층 | 지하 2층 이하 제외 (반지하·빈 값 유지) |
| 임대료 | 0원 제외 (전세 오분류), 400만 원 이상 제외 (법인·단기임대성 일괄 계약) |
| 보증금 | 0원 유지 (무보증 월세), 위쪽 제한 없음 |
| 임대면적 | 85㎡ 이하 |

정제 후 453,682건, 법정동 394개

## 결과 파일 (`src/main/resources/data/`)

### neighborhoods.csv — 후보 동네 (394줄)
| 컬럼 | 설명 |
| --- | --- |
| gu | 자치구 |
| dong | 법정동 |
| contract_count | 정제 후 월세 계약 건수 |
| lat, lng | 동네 중심 좌표 (카카오 로컬 API 주소 검색) |

### rent_contracts.csv.gz — 월세 계약 (453,682줄, gzip 압축)
| 컬럼 | 설명 |
| --- | --- |
| gu, dong | 자치구, 법정동 (neighborhoods와 연결) |
| building_type | 단독다가구 / 연립다세대 / 오피스텔 |
| area | 임대면적 (㎡) |
| floor | 층 (-1 = 반지하, 빈 값 = 층 정보 없음) |
| deposit | 보증금 (**만원**) |
| rent | 월세 (**만원**) |
